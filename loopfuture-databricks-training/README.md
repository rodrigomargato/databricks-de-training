# LoopFuture · Databricks Data Engineering Training

Training material for the **Databricks Certified Data Engineer Associate** path
(16 Nov – 7 Dec 2026), following the Databricks Customer Academy.

## Structure

```
GETTING_STARTED.md   step by step: GitHub repo + Databricks Git folder
week1/   Foundations: platform, Python & PySpark, Delta, COPY INTO, medallion, jobs
docs/    data_dictionary.md – the ShopLoop dataset used in all exercises
```

## 👉 First time? Follow [GETTING_STARTED.md](GETTING_STARTED.md)

## How to use this repository

1. Create your **Databricks Free Edition** account: https://www.databricks.com/learn/free-edition
2. Create **your own** GitHub repository and link it to Databricks (steps in `week1/00a_Workspace_Tour_and_Git_Setup`)
3. Import the notebooks of the week into your Git folder and run them in order
4. Commit & push your work at the end of each notebook
